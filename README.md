# Hospitality Revenue Data Analysis | SQL + Power BI + Tableau + Excel

## Project Overview
End-to-end data analysis of hospitality industry datasets to monitor 
revenue, bookings, and occupancy trends across multiple properties.

## Key Insights
- Tracked revenue, booking patterns & occupancy across properties
- Built pricing strategy insights using demand forecasting models
- Identified high and low performing properties by revenue KPIs
- Supported management decisions through data-driven dashboards

## Tools Used
- SQL — data extraction, complex queries, aggregations
- Power BI — DAX, interactive KPI dashboards, Power Query
- Tableau — visual analytics, filters, LOD expressions
- Excel — data cleaning, Pivot Tables, Power Query analysis

## Files in this Repository
- SQL queries (.sql)
- Power BI dashboard (.pbix)
- Tableau dashboard (.twbx)
- Excel analysis (.xlsx)
- Dashboard presentation (.pptx)
